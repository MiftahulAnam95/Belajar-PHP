Roadmap Materi

Belajar PHP dari dasar sampai project siap deploy

Alurnya dibuat pelan: nyalakan server lokal, tulis PHP pendek, baca form, simpan data, amankan output, lalu gabungkan semuanya menjadi project yang rapi.

Cara menggunakan materi

Tidak perlu menghafal semuanya sekaligus

Targetnya bukan cepat selesai. Targetnya bisa menjelaskan ulang dengan bahasa sendiri, seperti sedang mengajari teman sebangku.

Baca pelan-pelan

Mulai dari bagian "Mulai dari sini", pahami tujuan kecilnya, lalu bayangkan manfaatnya di project nyata.

Ketik dan ubah kode

Jangan hanya menyalin. Ubah nama, angka, pesan, atau kondisi supaya hubungan kode dan hasil terlihat jelas.

Lanjut saat sudah paham

Gunakan "Cek sebelum lanjut". Kalau belum bisa menjawab, ulangi contoh kecilnya dulu. Itu normal.

Peta belajar

Lima level menuju project PHP

Setiap level punya tujuan yang mudah dilihat, jadi siswa tahu kenapa materi itu dipelajari.

Daftar Materi

Mulai dari server lokal, lanjut ke form, data, database, dan CRUD
