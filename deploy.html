Checklist Deploy

Pastikan project PHP siap dipindahkan ke hosting

Gunakan halaman ini setelah mini project berjalan di localhost. Tujuannya sederhana: project tidak error, input aman, folder rapi, dan pengaturan penting mudah diubah.

Urutan aman

Lima langkah sebelum upload

Ikuti dari atas ke bawah. Kalau satu langkah belum beres, selesaikan dulu sebelum lanjut.

01

Coba semua fitur di localhost

Project harus bisa dijalankan dengan server lokal sebelum dipindahkan.

  1. Jalankan php -S localhost:8000.
  2. Coba buka halaman utama, kirim form, simpan data, edit, hapus, dan upload jika ada.
  3. Catat error yang muncul lalu perbaiki satu per satu.
02

Amankan input dan output

Semua data dari pengguna harus diperiksa sebelum dipakai.

  1. Gunakan trim dan cek field kosong.
  2. Gunakan htmlspecialchars saat menampilkan input pengguna.
  3. Gunakan prepare dan execute untuk query database.
03

Rapikan folder dan konfigurasi

Project yang rapi lebih mudah diperbaiki saat sudah online.

  1. Simpan asset di folder assets atau public.
  2. Simpan file data di folder khusus, misalnya data.
  3. Pisahkan koneksi database ke file config.php.
04

Matikan error detail untuk pengunjung

Error detail berguna saat belajar, tetapi tidak cocok ditampilkan di website online.

production.php Contoh pengaturan sederhana.

1<?php
2ini_set("display_errors", "0");
3error_reporting(E_ALL);
05

Upload dan uji ulang

Setelah upload, cek lagi dari browser seperti pengunjung biasa.

  1. Upload file project ke folder website hosting.
  2. Buat database dan sesuaikan nama host, user, password, dan database.
  3. Buka website, coba fitur utama, lalu cek apakah data benar-benar tersimpan.
