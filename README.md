# Belajar PHP

Website belajar PHP interaktif untuk pemula total. Bahasanya dibuat pelan, jelas, dan praktis agar bahkan anak SD yang sudah pernah melihat HTML dasar bisa memahami alur membuat project PHP sampai siap dipindahkan ke hosting.

## Tujuan belajar

Siswa tidak hanya hafal kode. Siswa dilatih memahami alur lengkap:

1. Browser meminta halaman.
2. Server menjalankan PHP.
3. PHP membaca input dan data.
4. PHP mengirim HTML ke browser.
5. Project dirapikan, dicek, lalu siap deploy.

## Fitur

- 20 materi PHP dari dasar dengan tujuan kecil di setiap pelajaran.
- Bahasa sederhana, analogi sehari-hari, istilah penting, dan contoh kode pendek.
- Quiz, recall challenge, latihan debugging, dan progress belajar.
- Simulator alur `index.php`, `data.php`, template PHP, dan CSS di browser.
- Mini project bertahap: form, JSON, session, CRUD, dashboard, dan buku tamu.
- Checklist project siap deploy: validasi, keamanan output, struktur folder, file konfigurasi, dan cara menjalankan di server lokal.

## Cara belajar yang disarankan

1. Baca tujuan materi.
2. Ketik ulang kode, jangan hanya menyalin.
3. Ubah satu nilai kecil dan lihat hasilnya.
4. Jawab recall dengan bahasa sendiri.
5. Tandai selesai jika sudah bisa menjelaskan ulang.
6. Setelah materi dasar selesai, rakit mini project dan cek daftar siap deploy.

## Menjalankan

Website utama dapat dibuka sebagai situs statis. Untuk praktik PHP asli, buka terminal di folder project PHP lokal lalu jalankan:

```bash
php -S localhost:8000
```

Lalu buka `http://localhost:8000` di browser.
