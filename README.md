# Belajar PHP

Website belajar PHP interaktif untuk pemula, melanjutkan seri Belajar HTML, CSS, dan JavaScript sebelum masuk Laravel.

## Fitur

- 20 materi PHP dari dasar dengan panduan langkah demi langkah
- Istilah penting, kesalahan umum, dan cek pemahaman pada setiap materi
- Quiz, recall challenge, dan latihan debugging
- Simulator alur index.php, data.php, template PHP, dan CSS di browser
- Ide mini project PHP
- Progress, badge, dan tema yang tersimpan di browser

## Menjalankan

Website utama dapat dibuka sebagai situs statis. Untuk praktik PHP asli, buka terminal di folder project PHP lokal lalu jalankan:

```bash
php -S localhost:8000
```
